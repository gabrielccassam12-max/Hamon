# Jojo Fighting Styles (Fabric 1.21.1)

Hamon, Spin e Vampirismo, com 7 técnicas cada, ranks e partículas de cubos brilhantes.
Só precisa do Fabric API.

## Como conseguir os estilos
- **Máscara de Pedra** (tijolos de pedra + olho de ender + obsidiana): vira vampiro.
- **Manual do Hamon** (livro + barra de ouro + girassol): aprende Hamon. Usar de novo = +100 XP.
- **Bola de Aço** (ferro + pepita de ouro, dá 4): aprende Spin. Precisa ter uma no inventário para usar as técnicas.
Hamon e Vampirismo não combinam (um rejeita o outro).

## Teclas
Z X C V B N M = técnicas 1 a 7 · Y = trocar de estilo · U = menu

## Comandos (op)
/styles give hamon|spin|vampire · /styles rank 0-5 · /styles master · /styles energy N · /styles reset

## Config
config/fightstyles.json (custo, recarga, dano, sol queima vampiro, densidade de partículas, tremor de câmera...)
